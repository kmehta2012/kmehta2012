# Hi, I'm Karan

I'm a computer science and mathematics graduate interested in algorithms, theoretical computer science, and systems. I like taking ideas from first principles to working implementations—and explaining why they work along the way.

## Now

My work is converging on the boundary between mathematical reasoning and computation: algorithms, search, machine learning fundamentals, and systems-level implementation.

## Featured Projects

- **[Randomized Algorithms Explainer](https://kmehta2012.github.io/Randomized-Algs-Explainer/)** — An interactive introduction to randomized algorithms, built with Quarto and D3.js and grounded in examples such as Freivalds' algorithm. It placed **11th of 44** entries in SoME 2026. [Source](https://github.com/kmehta2012/Randomized-Algs-Explainer)
- **[2×2 God's Algorithm](https://github.com/kmehta2012/2-by-2-GodsAlgorithm)** — A Python solver that models the cube's legal states as a graph and uses bidirectional breadth-first search to return a shortest solution.
- **[Feedforward + Backprop from Scratch](https://github.com/kmehta2012/Feedforward-backprop-from-scratch)** — A NumPy implementation of linear, activation, softmax, and loss modules, with forward propagation, backpropagation, and training tests.
- **[Concurrent Web Server in C](https://github.com/kmehta2012/concurrent-webserver-c)** — Systems work involving sockets, HTTP parsing, request handling, robust I/O, and pthread-based concurrency.
